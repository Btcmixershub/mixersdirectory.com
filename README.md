## 💡 Why mix bitcoin?

Every Bitcoin transaction is public and permanent. Anyone can follow coins from address to address, and once a single address is tied to your identity, your whole history can be traced.

Mixing services pool coins from many users and send back fresh coins with no visible on-chain link to the originals. It's the same idea as paying with cash instead of a card.

## ✅ Before you mix

```text
[ ] Opened the service via the official link from a trusted directory
[ ] Connected through Tor Browser
[ ] Saved the letter of guarantee (PGP-signed)
[ ] Set several output addresses with random delays
[ ] Checked current network fees in the mempool
```

## 🚩 Red flags

- ❌ No letter of guarantee
- ❌ Fees that look too good to be true (under 0.5%)
- ❌ Asks for email, phone number or ID
- ❌ Domain is one letter off from the original
- ❌ Listed in the **service graveyard** on [Mixers Directory](https://mixersdirectory.com/)
